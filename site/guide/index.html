How this storefront moves

The home page is Expressive: ScrollSmoother, a pinned scene, a rail. This page is Reading: native scrolling, decoration on CSS timelines, entrances that play once. Both are built from the same blocks.

One scroll authority per page

A page has exactly one scroll authority: native (the browser), Lenis (it smooths the real scroll position) or ScrollSmoother (it moves a transformed content wrapper). Two owners fight over the same position every frame.

Native is the default for reading-first and accessibility-first pages, like this one. ScrollSmoother suits a page that is GSAP only and leans on data-speed and data-lag, with its fixed UI outside the content wrapper: the home page. Lenis is the choice whenever a page mixes engines.

The owner stamps itself on <html data-scroll-authority>. Here it reads native; on the home page, smoother.

Four clocks

Every animation runs on one of four clocks: trigger (it plays once when content arrives), scroll (a function of the reader's position in a range), media (it follows what a video decoder presents) and render (a render loop). Name the clock first: it decides the cost, the engine and which traps apply.

The paragraphs on this page run on the trigger clock. The bar under the header runs on the scroll clock, with no JavaScript at all.

Reduced motion is an alternate scene

prefers-reduced-motion: reduce doesn't mean the same animation, faster. It means a composition with no positional movement that still tells the story.

Here, that is every entrance shown at rest, this heading unsplit, and the bar and the parallax gone. On the home page ScrollSmoother runs in its native mode, the pinned scene collapses to normal flow and the rail becomes a native scroller that snaps panel by panel. Both pages follow the setting live.

Content reads without JavaScript

Hidden entrance states apply only under html[data-animation="on"], which an inline script in the head sets before the first paint. A reader with JavaScript off sees every word, and if no engine boots within 4 seconds a CSS failsafe reveals the page.

The home page's headline is split into words when the site is built, and CSS animates it from the first frame: nothing on its path to the first paint waits for a script.

Checked in three engines

The site's checks drive both pages in Chromium, WebKit and Firefox: the scroll authority each page stamps, the pinned timeline rising through its pin, the rail's track moving, every entrance landing, reduced motion, JavaScript off, layout shift during load, and mount() creating the blocks in page order and leaving nothing behind.
